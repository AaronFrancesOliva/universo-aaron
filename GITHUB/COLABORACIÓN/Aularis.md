# Aularis

Sistema de **reserva de aulas y gestión de espacios para centros de FP** (aulas, equipamiento, reservas recurrentes, incidencias, turnos, ciclos y auditoría). Monorepo pnpm: API Laravel 12 + Sanctum con ~125 rutas y Swagger, interfaz React compartida entre web (Vercel) y escritorio (Electron, con instalador), PostgreSQL en Supabase y CI/CD con GitHub Actions. Equipo de 3 con Git Flow y 46 PR.
