# CanvaDIOP

App de escritorio para el **Departamento de Orientación Laboral**: importa un Excel de alumnos (nombre, DNI, curso, ciclo, módulo) y genera los **documentos de convalidación** con plantillas de Word según el número de módulos (1-10), en Word y PDF. Tiene reconocimiento de voz. React + Electron. Repositorio de JaviiCode, con un solo commit; en local hay cambios sin commit.
