  2. A + B ⋅ C = A ⋅ B + A ⋅ C ,   A ⋅ ( B + C ) = ( A + B ) ⋅ ( A + C ) A + B \cdot C = A \cdot B + A \cdot C,\quad A \cdot \left( B + C \right) = \left( A + B \right) \cdot \left( A + C \right)

  3. A + B ⋅ C = ( A + B ) ⋅ ( A + C ) ,   A ⋅ ( B + C ) = A ⋅ B + A ⋅ C A + B \cdot C = \left( A + B \right) \cdot \left( A + C \right),\quad A \cdot \left( B + C \right) = A \cdot B + A \cdot C

  4. Ninguna de las anteriores

La solución correcta es la 'c'.
